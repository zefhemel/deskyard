Applications
============

Put AppImages here to add them to the applications menu.

- Save or move an .AppImage file into this folder. Within a few seconds it
  shows up in the applications menu with its own name and icon. From there
  you can pin it to the dock.
- Or right-click an AppImage anywhere in the file manager and choose
  "Add to Applications Menu". That moves it here.
- To remove an app, delete its AppImage from this folder. Its menu entry
  goes away too.

The files don't need to be executable; that is fixed for you. AppImages for
another processor type (for example x86_64 on an ARM computer) are skipped.

Each launch unpacks the AppImage first, so big apps take a moment to start.
If the app is also on Flathub, installing it from Software starts faster.
