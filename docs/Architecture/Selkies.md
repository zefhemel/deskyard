Streams the desktop's screen, sound, mic, webcam and gamepads to browsers: Selkies 2.1.0 (in `/opt/selkies`, with a pinned pcmflux wheel and pixelflux 2.2.1 built from source) in WebSocket mode, as `user`, on `127.0.0.1:6080` behind [[Architecture/Caddy]], which passes only its stream (`/api/websockets`) and health probe through. The X server is Debian's Xvfb on display `:1` (a 3840x2160 framebuffer, modes added with `xrandr`); sound comes from the PipeWire speaker's monitor (`deskyard-speaker.monitor`), and Selkies' virtual mic is the default source. Pixelflux and pcmflux only run while someone is viewing. Settings: Turbo off, CSS scaling on, browser cursors, keyboard shortcuts, sidebar, printing, sharing and Selkies' own file transfers off (uploads and downloads are the supervisor's), mic and gamepads on (through Selkies' LD_PRELOAD joystick interposer in the session), and the webcam on only when the desktop has a virtual camera. The supervisor serves Selkies' web client from the desktop's image, not from the desktop (see [[Architecture/Desktop proxy]]). Files: `images/common/rootfs/usr/local/bin/start-xvfb`, `images/common/rootfs/usr/local/bin/start-selkies`, `images/common/rootfs/etc/supervisor/conf.d/workspace.conf`.

Three Deskyard patches cut what an idle desktop costs (with one idle viewer, from about 7.5 % of a core to about 1.1 % with all three on; the audio gate is off as shipped, which adds back 0.6–1.4 %), applied at build time; the build fails if one doesn't apply exactly. pixelflux is built from source in its own Dockerfile stage (`pixelflux`) because one of them is Rust: the `2.2.1` source checked by SHA-256, its codec libraries (libvpx, SVT-AV1, dav1d, libde265, x264, x265) built by pixelflux's own wheel script and installed in `/opt/pixelflux/lib`, and Rust pinned in `RUST_VERSION`.

- **Key timers** (`selkies-key-timers.diff`): Selkies' key auto-repeat and stale-key loops sleep while no key is held, instead of running at 50 and 10 Hz from startup, viewer or not.
- **Idle grab** (`pixelflux-idle-grab.diff`): pixelflux skips copying and hashing the screen on a tick where X DAMAGE reported nothing and the encoder has settled, grabbing once a second as a keepalive; damage, a keyframe request or a new viewer wakes it at once. `PIXELFLUX_IDLE=0` turns it off; `PIXELFLUX_IDLE_AFTER_MS`, `PIXELFLUX_IDLE_KEEPALIVE_MS` and `PIXELFLUX_IDLE_QUIET_FRAMES` tune it.
- **Audio gate** (`selkies-audio-gate.diff`): stops recording the speaker after `DESKYARD_AUDIO_IDLE_S` seconds with no stream playing into it, and starts again when one does. **Off by default** (start-selkies sets `DESKYARD_AUDIO_IDLE_S=0`): it saves only 0.6–1.4 % of a core per watched desktop, and loses the first ~90 ms of every sound after silence, which swallows short sounds such as chat pings and the terminal bell without telling anyone. An image built on this one switches it on with `ENV DESKYARD_AUDIO_IDLE_S=3`.

Details and measurements: `images/common/patches/README.md`.
