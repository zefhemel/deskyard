One desktop: a container from a desktop image and its [[Architecture/Workspace folder]], run only by the supervisor. The images (`images/Dockerfile`, built together by `docker-bake.hcl`) share one Debian trixie runtime with separate XFCE and MATE layers (see [[Architecture/Desktop runtime]]); `supervisord` (`images/common/rootfs/etc/supervisor/conf.d/workspace.conf`) starts its services, all as the single user `user` except D-Bus' system bus, Caddy (as `caddy`) and supervisord itself. No sudo. Remote clients map ports into and out of it through `deskyard forward-helper`, run by the supervisor (see [[Architecture/Port forwarding]]). A separately built custom image can add mise tools in `/opt/mise` (linked into `/opt/deskyard/bin`), system-wide Flatpak apps and, on first start, a home template from `/opt/deskyard/home-template` copied into the folder without overwriting anything (see the historical [[Architecture/Recipes|Recipes page]] for retained runtime behavior). The details page lists mise tools with where each comes from, the desktop or the image. What programs inside it do goes to its [[Architecture/Activity stream]], which the supervisor reads for [[Architecture/CLI activity]].
